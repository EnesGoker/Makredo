# ADR 0002: Target .NET 10 LTS on Windows

- Status: Accepted
- Date: 2026-11-05

## Context

Makredo needs a supported runtime for its beta and v1.0 releases. Windows-specific
input and WinForms code must coexist with application logic that can be tested on
the developer's Mac without a local Windows virtual machine.

## Decision

Target **.NET 10 LTS**, supporting **Windows 10 22H2 and Windows 11** on **x64 and
ARM64**. Use `net10.0` for portable projects and `net10.0-windows` for Windows
adapters and the WinForms application.

In T0.4, pin a .NET 10 SDK in `global.json` with `rollForward: latestFeature`,
update target frameworks and test packages, and enable Windows targeting for
builds on non-Windows hosts through `Directory.Build.props`.

## Consequences

The source import retains its original framework and SDK settings; accepting
this decision does not mean the migration has been implemented. T0.4 performs
the framework and SDK migration. T0.5 separates Windows adapters from portable
infrastructure, and T0.6 establishes separate Core and Windows test projects.

Core tests will run on macOS and other supported development hosts. Windows
tests will run in CI on x64 and ARM64 Windows runners, established in T0.7.
Windows tests and manual checkpoints are not treated as verified by a successful
Mac build.
